The critical transform: Sackmann is stored one row per match, with a winner and a loser side (winner_*/w_* and loser_*/l_*). Our schema needs one row per player per match. Data quality issues you must handle explicitly, not silently:

Match statistics are missing for many older and lower-tier matches — the w_ace/l_ace columns are blank. Do NOT fill these with 0; a missing ace count is not zero aces, and filling it would poison every rolling average. Leave them NULL and report what percentage of rows have stats.

Retirements and walkovers appear in score as RET, W/O, DEF, or as an abbreviated score. Add a match_completed boolean flag. Do not drop these rows, but flag them so features can exclude them later.

surface is occasionally blank. Leave NULL, report the count.

tourney_date is the tournament start date, not the match date — every match in a tournament shares it. This matters enormously for time-based splits and rolling windows. Store it as tourney_date, and add a separate event_date column that estimates the actual match date by offsetting from tourney_date based on round.
